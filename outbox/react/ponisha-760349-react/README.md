# روزرسانی اطلاعات ۶۰۰ مورد فایل اکسل — پروژه‌ی React آماده

این پوشه یک پروژه‌ی واقعی و قابل اجرا است که به‌طور خودکار از روی آگهی
«به روزرسانی اطلاعات ۶۰۰ مورد در فایل اکسل» ساخته شده است.

- سبک طراحی: **لاکچری طلایی** (`luxury_gold`)
- پالت رنگ: **طلایی لوکس** — تزریق‌شده به `tailwind.config.js` و `src/theme.js`
- فونت‌ها: "B Nazanin","Vazirmatn",Georgia,serif / "B Nazanin","Vazirmatn",Tahoma,serif

## اجرا

```bash
npm install
npm run dev          # http://localhost:5173
```

برای خروجی نهایی:

```bash
npm run build        # خروجی در dist/
npm run preview
```

## ساختار

```
src/
  theme.js           توکن‌های طراحی (رنگ، گرادینت، شعاع، افکت‌ها)
  content.js         همه‌ی متن‌های پروژه (فارسی)
  App.jsx            ترکیب صفحه
  components/        نوار، هیرو، خدمات، آمار، محصولات، گام‌ها،
                     قیمت، نظرات، سؤالات متداول، تماس، CTA، پاورقی
```

## نکته‌ها

- هیچ تصویر خارجی ندارد؛ تصویر هیرو یک SVG داخلی است (`components/HeroArt.jsx`).
- ریسپانسیو است (موبایل، تبلت، دسکتاپ) و جهتِ صفحه RTL است (`index.html`).
- دسترسی‌پذیری پایه رعایت شده: برچسب‌ها، نقش‌ها، حالت فوکس و منوی موبایل با `aria-expanded`.
- رنگ متن روی دکمه‌ها بر اساس کنتراست انتخاب شده است.
- برای تغییر رنگ/فونت/شعاع، فقط `src/theme.js` و `tailwind.config.js` را ویرایش کنید.
