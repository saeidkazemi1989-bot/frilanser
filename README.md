# فریلنس‌یار آرنا (frilanser)

اپی که **سایت‌های فریلنسری ایرانی را می‌گردد**، آگهی‌ها را از نظر
**«آیا این کار را می‌شود در آرنا انجام داد؟»** غربال می‌کند، برای گزینه‌های خوب
**دموی واقعی** و **قیمت پیشنهادی** می‌سازد، و هرجا که لازم باشد **شما وارد شوید**
(ثبت پیشنهاد در سایت، گرفتن دسترسی، تحویل پروژه) به شما اطلاع می‌دهد.

> تقسیم کار: **پیدا کردن + غربال کردن + ساخت دمو + قیمت‌گذاری + اجرا و آماده‌سازی خروجی = خودکار
> ثبت پیشنهاد در سایت فریلنسری و تحویل نهایی = با شما** (برای هر کدام متن/فایل آماده تحویل داده می‌شود)

---

## ۱. نصب و اجرا

```bash
git clone <این ریپو> && cd frilanser

# نصب وابستگی‌ها (دو راه)
./scripts/setup.sh                        # نصب در .pylib داخل پروژه (توصیه‌شده)
# یا: pip install -r requirements.txt

# اجرای کامل یک دور خط لوله (بدون اینترنت، از روی اسنپ‌شات‌های موجود)
python -m frilanser run

# داشبورد وب (تایید/رد، دیدن دمو، کپی متن پیشنهاد)
python -m frilanser serve              # http://localhost:5000
```

اگر پکیج‌ها را نمی‌خواهید در سیستم نصب کنید:

```bash
pip install --target .pylib -r requirements.txt
python -m frilanser run                 # مسیر .pylib خودکار اضافه می‌شود
```

> نکته: در محیط‌هایی که دسترسی به سایت‌های ایرانی مسدود است (مثل این sandbox)،
> برنامه به‌طور خودکار از **اسنپ‌شات‌های `data/raw`** استفاده می‌کند. روی سیستم
> خودتان با `--online` از سایت زنده می‌خواند.

## ۲. منابع (سایت‌های متصل‌شده)

| کلید | سایت | آدرس لیست |
| --- | --- | --- |
| `ponisha` | پونیشا | https://ponisha.ir/search/projects |
| `karlancer` | کارلنسر (همه‌ی پروژه‌ها) | https://www.karlancer.com/search |
| `karlancer_programming` | کارلنسر - برنامه‌نویسی | https://www.karlancer.com/jobs/programming |
| `karlancer_web_design` | کارلنسر - طراحی سایت | https://www.karlancer.com/jobs/web-design |
| `parscoders` | پارس‌کدرز | https://parscoders.com/project |

افزودن منبع جدید: یک کلاس در `frilanser/sources/` بسازید (از `BaseSource`
ارث‌بری، متد `parse`) و آن را در `config.toml` و `sources/registry.py` ثبت کنید.
در اولین اجرای `--online`، متن صفحه در `data/cache` ذخیره می‌شود؛ با کپی آن به
`data/raw/<کلید>-<تاریخ>.md` یک اسنپ‌شات آفلاین هم خواهید داشت.

## ۳. خط لوله (pipeline)

```
collect ──▶ screen ──▶ propose ──▶ demo ──▶ notify
  │           │           │          │         │
  │           │           │          │         └─ گزارش مارک‌داون + صف «نیاز به ورود شما»
  │           │           │          └─────────── دموی HTML تعاملی برای هر کاندید
  │           │           └────────────────────── قیمت، مراحل پرداخت، متن پیشنهاد
  │           └────────────────────────────────── دسته‌بندی، امتیاز اجراپذیری، زمان
  └────────────────────────────────────────────── خواندن آگهی‌ها (شبکه یا اسنپ‌شات)
```

### غربالگری: چه پروژه‌هایی «در آرنا قابل اجرا» هستند؟

* **بله (تحویل کامل):** استخراج/پردازش داده، اسکریپت و اتوماسیون، ربات/بات،
  اپلیکیشن هوش مصنوعی، وب‌سایت و وب‌اپ، لندینگ، داشبورد و گزارش‌ساز.
* **تا حدی:** افزونه/قالب وردپرس (کد تحویل می‌شود، نصب با شماست)، اپ موبایل
  (نسخه وب/PWA)، تولید محتوا و ترجمه (نیاز به بازبینی انسانی)، ورود داده.
* **خیر:** سئوی مستمر، طراحی گرافیک/لوگو/کاتالوگ، رندر و مدلسازی، تدوین و
  صدا، آموزش/تدریس/مشاوره، ادمین و پشتیبانی مستمر، سخت‌افزار و تأسیسات،
  ربات‌های معاملاتی.

امتیاز هر پروژه (۰ تا ۱۰۰) از روی این عوامل کم و زیاد می‌شود:
تناسب دسته، **تعداد رقبا**، بودجه و تناسب آن با برآورد ما، شفافیت توضیحات،
نیاز به دسترسی/نرم‌افزار لایسنس‌دار/عملیات انسانی، چندفازی بودن، و زمان اجرا.

خروجی: `candidate` (کاندیدا)، `review` (نیاز به بررسی)، `rejected` (رد شده)
— هر کدام **با دلیل فارسی**.

### قیمت‌گذاری

```
قیمت پایه = ساعت برآوردی × نرخ ساعتی × ضریب پیچیدگی
قیمت نهایی = قیمت پایه × (۱ + کمیسیون پلتفرم + حاشیه ریسک)  ← گرد شده
اگر بودجه‌ی کارفرما خیلی بیشتر از برآورد باشد → قیمت‌گذاری ارزش‌محور
اگر کمتر باشد → پیشنهاد جایگزین با محدوده‌ی کاهش‌یافته
```

همه‌ی این مقادیر در `config.toml` قابل تنظیم‌اند (نرخ ساعتی، کف قیمت، سقف ساعت، …).

## ۴. دستورها

```bash
python -m frilanser run            # یک دور کامل (collect→screen→propose→demo→report)
python -m frilanser run --online   # دریافت زنده از سایت‌ها
python -m frilanser scan --online  # فقط جمع‌آوری
python -m frilanser screen         # فقط غربالگری
python -m frilanser propose        # فقط قیمت‌گذاری
python -m frilanser demo --limit 5 # ساخت دمو برای کاندیداها
python -m frilanser report         # ساخت گزارش + صف «نیاز به ورود شما»
python -m frilanser list --verdict candidate
python -m frilanser show ponisha:760397
python -m frilanser needs --full   # کارهایی که باید خودتان انجام دهید (با متن پیشنهاد)
python -m frilanser decide ponisha:760397 approved --note "کارفرما پذیرفت"
python -m frilanser serve          # داشبورد وب
```

## ۵. گردش کارِ پیشنهادی (این همان چیزی است که خواستید)

1. **اسکن خودکار:** برنامه همه‌ی آگهی‌های جدید را می‌خواند و غربال می‌کند.
2. **دمو + قیمت برای گزینه‌های خوب:** برای هر کاندیدا یک دموی تعاملی و متن
   پیشنهادِ آماده ساخته می‌شود.
3. **اطلاع به شما:** در داشبورد (بخش «نیاز به ورود شما») و در گزارش
   `outbox/reports/YYYY-MM-DD.md` به شما گفته می‌شود چه کارهایی مانده است:
   * ثبت پیشنهاد در سایت (با متن آماده‌ی کپی‌کردن)
   * گرفتن دسترسی/اطلاعات از کارفرما
   * توافق روی شکل تحویل (مثلاً وردپرس یا سایت اختصاصی)
4. **تایید شما:** وقتی کارفرما پذیرفت، پروژه را در داشبورد «تایید» می‌کنید
   تا اجرا و آماده‌سازی خروجی شروع شود.
5. **تحویل با شما:** بعد از آماده شدن، در همان صفحه «تحویل داده شد» را می‌زنید؛
   فایل‌ها را در سایت بارگذاری می‌کنید.

## ۶. فایل‌ها

```
config.toml              تنظیمات (نرخ ساعتی، سقف زمان، منابع، …)
data/raw/                اسنپ‌شات‌های واقعی آگهی‌ها (json + متن خام برای تست پارسرها)
data/projects.json       وضعیت و تحلیل همه‌ی پروژه‌ها
data/needs_you.json      صف کارهایی که باید خودتان انجام دهید
outbox/demos/            دموهای HTML ساخته‌شده (هر کدام یک فایل مستقل)
outbox/reports/          گزارش روزانه (latest.md همیشه آخرین گزارش است)
frilanser/               کد برنامه (sources، screening، pricing، demo_builder، web)
tests/                   تست‌های خودکار
scripts/scan.sh          اجرای دوره‌ای (cron)
```

## ۷. تست

```bash
python -m pytest tests -q
```

## ۸. محدودیت‌ها

* **احترام به سایت‌ها:** بین درخواست‌ها تأخیر وجود دارد (`fetch.delay_between_requests`)
  و نتایج کش می‌شوند. پیش از اسکن گسترده، شرایط استفاده‌ی هر سایت را بخوانید.
* برنامه پیشنهاد را **برای شما آماده می‌کند**؛ ثبت آن در سایت (و احراز هویت،
  گفتگو با کارفرما، تحویل نهایی) عمداً دستی است.
* دموها با **داده‌های نمونه** ساخته می‌شوند تا خروجیِ نهایی را نشان دهند،
  نه اینکه ادعا کنند کار انجام شده است.
